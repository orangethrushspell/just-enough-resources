## About

**Just Enough Resources (JER)** is a well-known Minecraft mod that extends and enhances the base game experience.
This repository provides pre-built JAR files for both Legacy (Forge 1.16.5–1.17) and Modern (1.18–1.21+) Minecraft versions,
ready to drop into your mods folder without any additional setup.

> 🎮 Designed for survival, creative, and modpack use · Compatible with major mod loaders · No external dependencies

## Installation

1. Download the JAR file for your Minecraft version from the table above
2. Place the `.jar` file in your `.minecraft/mods/` directory
3. Make sure the appropriate mod loader (Forge / Fabric / NeoForge) is installed
4. Launch Minecraft and enjoy

> **Tip:** Always check the version table before downloading to avoid incompatibility.

## FAQ

**Q: Where do I put the JAR file?**
A: In your `.minecraft/mods/` folder. Create it if it doesn't exist.

**Q: Do I need other mods installed first?**
A: No extra dependencies required — just the mod loader for your version.

**Q: Will it work in a modpack?**
A: Yes. Both Legacy and Modern builds are modpack-friendly.

**Q: The mod isn't loading — what do I do?**
A: Make sure you downloaded the correct JAR for your Minecraft version and that your mod loader matches.
